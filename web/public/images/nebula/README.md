# Nebulosa — assets de referencia visual

Imágenes derivadas de captura de referencia para la sección Integraciones (animación híbrida).

- `nebula.webp` — fondo principal (~1600×1200)
- `nebula@2x.webp` — variante retina
- `nebula-poster.webp` — fallback estático y `prefers-reduced-motion`

Uso: fondo del contenedor `.nebula-scene`; la animación Three.js dibuja estrellas y flare encima.
